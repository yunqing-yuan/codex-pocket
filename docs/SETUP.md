# 安装、分享与排障

## 给第一次使用的人

先让电脑里的 Codex 可以正常发送消息并收到回复。若使用 cc-switch，先完成自己的服务配置与切换。Pocket 沿用这套配置，不会替你注册模型账号或提供额度。

从 [Releases](https://github.com/yunqing-yuan/codex-pocket/releases) 下载：

| 文件 | 用途 |
| --- | --- |
| `Codex-Pocket.apk` | Android 手机安装包 |
| `Codex-Pocket-Bridge.zip` | 电脑桥完整目录，含启动脚本和所需源码 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

电脑桥包也包含 `release/Codex-Pocket.apk`，方便通过配对页提供的下载地址给自己的手机安装。包内不含 Node.js、Codex、cc-switch 或任何账号配置。

1. 安装 [Node.js 20/22 LTS](https://nodejs.org/)，安装时保留加入 PATH 的选项。
2. 把整个 ZIP 解压到有写入权限的目录，不要在压缩包内直接运行。
3. 双击 `Start-Pocket.cmd`。Codex 桌面窗口可以关闭，电脑桥会后台启动引擎。
4. 浏览器打开本机配对页 `http://127.0.0.1:15732`。电脑有多个网卡时，选择手机可访问的 Wi-Fi / 以太网地址。
5. 手机安装 APK。如果系统阻止安装，为用于打开安装包的文件管理器临时允许安装未知来源应用。
6. 打开 App → 左上角对话记录 → 底部「设置与配对」，输入电脑地址和六位配对码。
7. 配对后选择已有对话，或新建对话并选择项目。

手机需要填写电脑的网络地址，不能填写 `127.0.0.1`，因为在手机上它指向手机自身。配对页的 `15732` 是本机管理端口，App 应连接 `15731`。

电脑桥在后台运行；关闭配对页不会停止它。需要查看前台日志或方便停止时，可在桥目录运行 `node desktop.mjs`，结束时按 Ctrl+C；不要与已有后台桥同时启动。已有后台桥可在任务管理器中按命令行定位 `node ... desktop.mjs` 后停止，避免结束其他 Node.js 程序。

## 分享给朋友

直接分享 GitHub Releases 链接，或转发原始 APK 与桥 ZIP。朋友仍需在自己的电脑安装依赖、配置模型服务并配对。不要压缩自己使用中的目录：`runtime/` 包含访问令牌、上传文件和日志。

## 一次配对，以后直接打开

1. 手机覆盖安装最新版 APK，不要卸载旧 App；现有配对会保留。
2. 电脑首次运行一次 `Enable-Background.cmd`，之后 Windows 登录后自动启动后台守护，不用打开 Codex 窗口。已启用旧版启动项的用户更新后再运行一次此脚本。
3. 联网打开 App，点开需要离线查看的会话，内容同步后会自动加密保存。以后即使离线重开 App，也保留上次打开的对话和文字草稿。
4. 恢复网络、电脑恢复在线或切回 App 时自动重连，无需重新输入配对码。离线时发送会保留草稿，连上后再点发送，不自动重放命令或审批。

配对码只用于首次交换凭据；配对码过期不影响已配对手机。主动清除应用数据、卸载、撤销电脑令牌或更换电脑需要重新配对。标题已同步但从未点开读取的历史内容，仍需联网获取。附件原文件和作品预览不提供离线保存；未发送附件在关闭 App 后需重新选择。本地聊天文件上限 64 MiB，保存失败会提示并保留上一次成功保存的文件，不会静默裁剪消息。

要在不同网络下直接连接，请先完成 [Tailscale 配置](REMOTE.md)，使用它分配的稳定地址，并保持两端 Tailscale 在线。普通 Wi-Fi 地址变化后需更新地址，不会自动搜索所有网络。

## 后台运行与屏幕隐私

首次配对后，双击 `Enable-Background.cmd`。它在当前 Windows 用户的启动目录创建一个快捷方式，并启动隐藏的电脑桥，不需管理员权限、不保存 Windows 密码。以后登录 Windows 后桥自动运行，守护脚本每 15 秒检查桥是否退出，退出后自动重新启动；手机可以发消息、新建会话和审批，无需打开 Codex 桌面窗口。

电脑需开机、登录并保持唤醒，可以锁屏；这不是远程开机，也不能绕过 Windows 登录。已经打开的桌面会话仍可能显示同步消息，外出前应锁屏。后台正在处理的会话在本轮完成后释放，电脑才能接管。

保持桥目录不变，移动后重新运行启用脚本。`Disable-Background.cmd` 移除启动项并结束守护检查，不终止当前桥或任务。`Start-Pocket.cmd` 用于主动查看配对信息。

## 会话与作品

- 归档：侧边历史点击会话旁「归档」，或在对话右上角「⋯」操作；在「已归档」中查看或恢复。正在运行或待审批时先完成任务。
- 思考：结构化 reasoning 内容默认隐藏；模型写在正常回复中的文字仍保留。
- 作品：对话右上角「⋯ → 查看作品」。列表来自回复链接和文件修改记录，仅访问当前项目内文件，单文件上限 20 MB。
- 图片、HTML、文本、音视频可直接预览。PDF 等格式可通过「分享 / 保存」交给其他应用。
- HTML 会嵌入项目内常见 CSS、脚本和图片，预览禁止外网请求；复杂模块或服务端接口需要电脑运行。分享的是原始文件，多文件网站需自行打包。
- 旧版新会话报记录文件不存在时，手机发送失败处可选「带入新对话」，再点发送。旧记录不自动删除，待发送的草稿和附件保留。

## 开启防火墙后无法连接

这是可选的网络排障工具，不是应用兼容性前置条件，也不修复会话记录文件缺失。此前运行过的用户，可用本节末尾的 `-Remove` 撤销它添加的规则。

如果关闭 Windows 防火墙就能连接，说明需要配置电脑桥的入站规则。请重新开启防火墙，再按以下步骤操作：

1. 在 Windows「设置 → 网络和 Internet → 当前 Wi-Fi / 以太网 → 网络配置文件类型」，把**自己的可信 Wi-Fi 或手机热点**设为「专用」。热点经常默认归为「公用」，因此只勾选 Node.js 的「专用」权限仍可能不生效。
2. 使用包含 `Fix-Firewall.cmd` 的新版电脑桥，完整解压并运行 `Start-Pocket.cmd`。
3. 右键 `Fix-Firewall.cmd` →「以管理员身份运行」，允许 Windows 的系统权限提示。
4. 回手机重新连接。手机 App 无需重装，地址仍以当前电脑配对页为准。

脚本只为实际运行桥的 Node.js 放行 **TCP 15731、专用网络、本地子网**，不关闭防火墙，不开放配对管理端口 `15732`。使用自定义端口时，在管理员 PowerShell 中运行 `./Fix-Firewall.ps1 -Port 你的端口`。Node.js 路径改变后重新运行脚本即可。

**若脚本提示存在 Node.js「阻止」规则：允许规则不能覆盖阻止规则。** 按 Win+R，输入 `wf.msc`，进入「入站规则」，按脚本显示的名称找到阻止规则。在「属性 → 高级 → 配置文件」中，仅对确定不需要阻止的 Node.js 规则取消「专用」，保留其他网络的限制。来自组织策略的规则请联系管理员。不要批量删除其他防火墙规则。

脚本检查的是当前 Node.js 的显式阻止规则；第三方防火墙或其他广泛阻止策略仍可能拦截。它也不替私人 VPN 创建放行规则。撤销本脚本添加的规则，可在管理员 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Fix-Firewall.ps1 -Remove
```

## 异地连接

推荐使用新版电脑桥中的 **`Setup-Remote.cmd`** 配置向导。手机首次安装 Tailscale、登录同一私人网络并允许 VPN，电脑按向导完成安装、登录和端口配置。详见 [异地连接指南](REMOTE.md)。以下为手动配置方式：

1. 自行在手机、电脑安装并配置 Tailscale 等私人 VPN。
2. 确认两台设备属于你允许互访的私人网络，防火墙允许桥端口。
3. 把 App 地址改为电脑 VPN 地址并保留 `:15731`，按需重新配对。
4. 电脑保持在线、登录、不休眠，桥保持运行；可以锁屏。

这不需要路由器公网端口映射。Pocket 不负责安装 VPN、创建账户或配置访问规则；本预览版尚未完成跨网络设备验证。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 启动提示找不到 Node | 安装 Node.js 后重新打开终端，确认 `node --version` 可用 |
| 找不到 `codex.exe` | 先启动 Codex；必要时设置 `CODEX_BIN` 为本机 `codex.exe` 路径，然后在同一终端运行 `node desktop.mjs` |
| 不显示地址或配对码 | 检查 `runtime/desktop-error.log`；确认 `15731`、`15732` 未被其他程序占用 |
| 手机连接超时 | 检查地址、端口、防火墙、电脑休眠；访客 Wi-Fi 可能隔离设备 |
| 防火墙关了能连、开了不行 | 按上方「开启防火墙后无法连接」设置可信网络为专用，并运行 `Fix-Firewall.cmd` |
| 配对码错误 / 过期 | 在电脑配对页生成新码，10 分钟内使用；次数过多时等待一分钟 |
| 提示电脑窗口不可用 / 协议不兼容 | 先更新并重启配套的桥；已打开的桌面会话依赖其 IPC 版本，后台执行不需打开窗口 |
| `already has an active writer` | 后台活跃任务结束后再由桌面接管；避免多个独立引擎同时写同一会话或运行多份桥 |
| 切换中转服务后模型列表不对 | 先确认电脑端使用新配置，再在无任务、无待审批时重启桥 |
| 附件不能解析 | 文件已传到电脑，但具体格式依赖 Codex 工具；尝试文本、常见图片或可读取的文档 |
| 安装提示签名冲突 | 本地自编译包可能使用不同签名。备份所需信息后卸载旧包，再安装并重新配对 |

`Restart-Pocket.cmd` 会检查桥进程、任务与审批状态；存在未完成事项时可能拒绝重启。优先完成或停止相应任务，再重试。

## 校验下载

PowerShell：

```powershell
Get-FileHash .\Codex-Pocket.apk -Algorithm SHA256
Get-FileHash .\Codex-Pocket-Bridge.zip -Algorithm SHA256
```

与同一 Release 的 `SHA256SUMS.txt` 比较。日志、截图发到公开渠道前请先移除配对信息、私人路径和会话内容。

## 发出消息后一直等待 / 电脑显示另一个应用占用

手机出现「等待模型继续回复」表示任务已经交给电脑，不代表需要重新输入 Windows 密码。模型服务可能长时间不返回内容；1.3.2 会显示等待时长、连接重试等状态。可以继续等待，或在手机点「停止本轮」，收到结束确认后再重试或选择其他模型。不会因为等待较久而自动中止你的长任务。

Codex 为同一会话限制一个写入者：手机后台本轮仍在处理时，桌面可能显示「已在另一个应用中打开」。等本轮完成，或在手机停止并确认结束，后台会释放会话；桌面旧页面需点「重试」。不要为解除会话锁删除聊天文件或结束所有 Codex 进程。

Windows 已登录后再锁屏可正常运行后台桥；开机后尚未首次登录时，当前用户启动项尚未运行。手机不会要求、保存或传输 Windows 密码。
